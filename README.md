# Notes app Frontend

A Notes Website is a responsive web application that allows users to create, organize, edit, and delete personal notes in a simple and user-friendly interface. The frontend is built using HTML, CSS, JavaScript and ReactJs to provide a smooth and interactive user experience. Users can easily add new notes, search through existing notes, and manage their information efficiently. The website features a clean design, responsive layout, and intuitive navigation, making it accessible across desktop, tablet, and mobile devices. Interactive elements such as buttons, forms, modals, and animations enhance usability while demonstrating core frontend development concepts.

Create new notes
Edit existing notes
Delete notes
Search notes by title or content
Responsive design for all screen sizes
Clean and modern user interface
Local storage support to save notes in the browser
User-friendly navigation and interactive elements

Technologies Used
HTML – Structure of the website
CSS – Styling and responsive design
JavaScript – Dynamic functionality and user interactions
ReactJs - Store in library
Local Storage API – Store notes without a backend
